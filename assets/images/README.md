# Image Assets

Place site images in this folder.

Recommended filenames:

- `hero-portrait.jpg` - Main portrait or author photo used for the hero area.
- `og-image.jpg` - Social sharing image for Open Graph / Twitter previews.
- `book-understory-season.jpg` - Cover image for *The Understory Season*.
- `book-field-notes-on-forgetting.jpg` - Cover image for *Field Notes on Forgetting*.
- `book-where-the-slow-water-goes.jpg` - Cover image for *Where the Slow Water Goes*.
- `favicon.png` - Browser tab icon.

If you add real images later, this is the folder to use.
